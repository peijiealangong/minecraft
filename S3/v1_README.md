# Wildlands

Run a local server from the project folder:

    python3 -m http.server 8000 --directory outputs

Open http://localhost:8000/ in a modern desktop browser. Three.js is loaded from jsDelivr, so the first launch needs an internet connection. World saves stay in that browser's local storage.

## Controls

- W A S D: move; mouse: look
- Space: jump (fly up in Creative); Shift: sprint (fly down in Creative)
- Left mouse: break blocks / attack; right mouse: place blocks / interact
- 1–9 or mouse wheel: select hotbar slot
- E: inventory and crafting; F: eat selected food
- M: switch modes; Esc: pause

If mouse capture is unavailable, drag on the game view to look around.
